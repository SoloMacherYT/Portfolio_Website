Personal Portfolio Website
Overview

This is my personal portfolio website created to serve as a simple digital introduction of myself. It includes basic information about my skills, background, and contact details. The project was built as part of my learning journey in web development.

Goals
Create a basic online presence to represent myself
Practice frontend development fundamentals
Experiment with layout, structure, and color palettes
Learn by building a real-world personal project
Features
Simple static layout
Basic sections for introduction, skills, and contact information
Custom color palette (partially assisted using AI tools)
Minimal design without advanced UI/UX enhancements
Tech Stack
HTML
CSS
JavaScript ( Working on it)
Notes
The design is intentionally minimal and not fully optimized for mobile devices
UI/UX improvements were not the main focus of this project
Some design elements and color choices were assisted using AI tools
Learning Outcome
Understood how to structure a personal website
Gained experience in basic frontend development
Learned how to iterate on design ideas using AI assistance
Improved confidence in building and publishing small projects
